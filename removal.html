Stop Watchword being removed

Watchword can close any search, but on its own it can't stop someone removing it.

Back to Watchword settings

Why this matters

Any browser extension can be removed from the extensions page in two clicks, and browsers don't let an extension prevent it. So in a weak moment, Watchword is only as strong as the urge to remove it. The lock below closes that gap.

How the lock works

Windows has settings, made for schools and workplaces, that install an extension and keep it there. With them on, the Remove and Turn off buttons disappear, and Watchword comes back by itself if anything deletes it. The same settings turn off private windows and guest mode, where Watchword can't run.

Whoever has the computer's administrator password can still undo it. That's why the last step gives that password to someone you trust: the person the lock protects shouldn't hold its key.

Lock it in place on Windows

  1. Use the store version. Install Watchword from your browser's add-on store. Copies loaded from a folder can't be locked, so if you have one, remove it and turn off Developer mode.
  2. Set up the computer's filter first. Follow the Windows guide in Protect every device while you're still an administrator. After step 5 it needs the other person's password.
  3. Download the lock files. They're on Watchword's GitHub page, where anyone can read exactly what they change. Inside are Watchword lock.reg, Watchword unlock.reg and HOW TO USE.txt. Download the lock files See what they change
  4. Run the lock. Double-click Watchword lock.reg and click Yes, Yes and OK. Then close the browser completely and open it again. The status at the top of this page should now say Watchword can't be removed.
  5. Hand over the key. Make a second administrator account for the person you trust, and let them switch your own account to Standard. HOW TO USE.txt walks through it. From then on, undoing the lock needs their password.
  6. Keep the unlock file away from yourself. Give Watchword unlock.reg to the person you trust, or delete it. It can always be downloaded again, and it needs their password to run.

After locking, the browser says it's “managed by your organization”, and Edge's own secure DNS setting is greyed out. Both are expected: here the organization is you, and the browser uses the computer's DNS filter instead.

What it doesn't cover

Other browsers. The lock covers the browsers Watchword is in. The computer-wide filter from Protect every device covers the rest.

Phones. Extensions don't run there, so the phone guides use a DNS filter and Screen Time instead.

Macs and other computers. The lock is for Windows only for now.

This page only checks, on this device, how Watchword was installed. Watchword sends nothing anywhere.
