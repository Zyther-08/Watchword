1. Filter the whole computer

This covers every browser and app on the computer. Wi-Fi and a cable (Ethernet) are set separately, so do it for each one you use.

  1. Open your connection's settings. SettingsNetwork & internetWi-Fi or Ethernet On Wi-Fi, open the properties of the network you're connected to.
  2. Switch DNS to manual. Next to DNS server assignment, click Edit and choose Manual.
  3. Enter the filter's addresses. Turn on IPv4. Enter 1.1.1.3 as Preferred DNS and 1.0.0.3 as Alternate DNS.
  4. Turn on encryption. For DNS over HTTPS, choose On (manual template) and enter the secure DNS address https://family.cloudflare-dns.com/dns-query. If your Windows only offers On (automatic template), choose that. Turn Fallback to plaintext off.
  5. Do the same for IPv6. Turn on IPv6 and enter 2606:4700:4700::1113 and 2606:4700:4700::1003, with the same encryption settings. Some networks use IPv6, and this closes that gap.
  6. Save. Windows asks for an administrator password. That's good: it means everyday accounts can't change this back.

2. Filter the browsers too

Browsers can use their own secure DNS and skip the computer's setting, so point each browser you have at the filter as well.

  1. Edge. edge://settingssearch “secure DNS” Turn on Use secure DNS, pick Choose a service provider, and enter the secure DNS address.
  2. Chrome. chrome://settings/securityUse secure DNS Choose to add a custom provider, and enter the secure DNS address.
  3. Firefox. SettingsPrivacy & SecurityDNS over HTTPS Choose Max Protection, set the provider to Custom, and enter the secure DNS address.

3. Make it hard to undo

  1. Use a standard account every day. SettingsAccountsOther usersAdd account Choose to add a user without a Microsoft account. New accounts are standard accounts, which can't change the computer's DNS. Use it for everyday browsing, and keep the administrator account only for changes.
  2. Install Watchword in the new account too. Each Windows account has its own browsers and extensions, so set Watchword up again there.
  3. Give the administrator password away. Ideally to someone you trust. If there's no one, keep it written down somewhere inconvenient, away from the computer.

1. Filter the whole phone

Private DNS covers every app and browser, on Wi-Fi and on mobile data. If you'd also like GIF search in the keyboard off, use NextDNS from step 3 instead.

  1. Find Private DNS. Open Settings and type Private DNS in the search bar at the top. Menus differ between phone makers; searching finds it on all of them. Pixel: Network & internetPrivate DNS Samsung: ConnectionsMore connection settingsPrivate DNS
  2. Choose a provider name. Select Private DNS provider hostname.
  3. Enter the filter and save. Type family.cloudflare-dns.com exactly, then tap Save.

2. Check Chrome

  1. Make Chrome follow the phone's filter. ChromeSettingsPrivacy and securityUse secure DNS Leave it on your current service provider so Private DNS applies, or choose a custom provider and enter the secure DNS address.

Chrome on Android can't run extensions, so Private DNS is what filters it, along with every other browser on the phone.

3. Optional: turn off GIF search in the keyboard

Most GIFs are harmless, but GIF search in keyboards like Gboard and Samsung Keyboard, and in apps like WhatsApp, can show some that aren't, and it can't be filtered by word. This step turns GIF search off completely, not just the bad ones. GIFs people send you usually still show, because they arrive with the message. Skip it if GIF search isn't a problem for you.

Cloudflare's filter can't do this, because it doesn't let you add addresses of your own. NextDNS can, and it's free. Its website is easiest to set up on a computer.

  1. Make a free NextDNS account. Sign up at nextdns.io. It makes a filter for you straight away.
  2. Block adult websites. Parental ControlCategories Add Porn. On the same page, turn on SafeSearch, YouTube Restricted Mode and Block Bypass Methods.
  3. Block the GIF services. Denylist Add each of these. Each one also blocks every address under it.
    • tenor.com
    • tenor.co
    • tenor.googleapis.com
    • giphy.com
  4. Point Private DNS at NextDNS. On NextDNS's Setup page, copy the Private DNS name shown for Android. Enter it where step 1 says family.cloudflare-dns.com.
  5. Check it with a harmless word. Open the keyboard's GIF search and search a word you haven't searched there before, like “ball”. If no pictures load, it's blocked. GIFs you've seen before can still show for a while, because the phone has saved them.

The free plan covers 300,000 lookups a month. A busy phone can use that up near the end of the month, and then filtering stops until the 1st. NextDNS's Analytics page shows how fast you're going, and the paid plan has no limit.

Android has no built-in lock for your own Private DNS setting, so on your own phone this one stays a speed bump. On a child's phone, Google Family Link lets a parent manage the phone's settings and filter Chrome. Filter every device on your Wi-Fi

One setting covers every phone, computer, tablet and TV on the home Wi-Fi, including guests' devices.

  1. Find the router's address. It's usually printed on a sticker on the router, often 192.168.0.1 or 192.168.1.1. Type it into the address bar of a browser on a device connected to that Wi-Fi.
  2. Log in. The password is often on the same sticker.
  3. Find the DNS settings. Depending on the brand, they're under Internet, WAN, or LAN and DHCP.
  4. Write down what's there now. Then you can always put it back.
  5. Enter the filter and save. Enter 1.1.1.3 and 1.0.0.3, and the IPv6 addresses if there are IPv6 fields. Save, and restart the router if it asks.
  6. Change the router's password. Replace the password from the sticker with a new one, and give it to someone you trust. Otherwise anyone can change the filter back.

Some routers from internet providers don't allow changing DNS. If yours doesn't, the device guides do the same job. Phones on mobile data and browsers with their own secure DNS skip the router, so the other guides still matter.

There's no need to visit a blocked site to test any of this. If you saved the settings, the filter is on.
